## 本次收尾顺序（已完成）

1. 修复 B02/B03 的已确认缺陷，补 B04 客服/编码模板组合用例和可复制教程。
2. 运行用户批准的核心链路定向测试，不跑全量测试；保留每组命令和结果，不沿用历史通过数。
3. 有可用 Docker 环境后运行现成的 `tests/integration_docker_smoke.py`，使用已缓存镜像且禁止拉取。启动 Docker 或新增安装需用户决定。
4. 更新正式版本元数据，构建 wheel/sdist，在仓库外的临时隔离环境安装本地候选包，验证导入、依赖一致性、CLI/TUI。只有通过后才上传正式版；不能把改版本号当成完成。

当前不调用真实模型，不安装全局依赖，不自动提交/推送 Git。真实厂商质量、计费和所有平台组合未验收，不包装为已通过。

## 正式版之后：优化与保留设计

这些不是本次新增门禁，已有实验性实现也不因正式包发布自动获得稳定性承诺：

- 模型与计量：更多厂商多模态细节、原生游标贯通所有前端、自动更新价格、精确跨服务逐 Run 归因。
- 知识与存储：语义分块、归档 GC/加密、跨库原子事务、自动化远端异常对账及高级索引维护。
- 插件与分享：运行中消费者自动重绑/状态迁移、在线市场、自动更新、跨语言插件 SDK、签名信任网络。
- 执行与编排：额外 Agent 类型、多 Agent、分布式/嵌套 Workflow、通用远端沙箱、所有系统上的 Wasmer/nsjail 验收。
- 交互：更丰富的媒体播放、专用语音链路、在线评测平台。

仍然不做：托管平台、多租户、组织/云计费、导入分享码后自动执行第三方代码。发现违背上述基本承诺的真实缺陷可以阻塞发布；新增强想法进入路线图，不扩张基础发布范围。
