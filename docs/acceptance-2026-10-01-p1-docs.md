## 验收方法与结果

本轮只使用文件读取、源码签名核对、标准库 AST 解析、Markdown 本地链接/标题检查、SHA-256 对比和 Git 空白检查。临时检查器不导入项目，不执行 README 示例；没有运行 pytest、编译、安装、构建、模型调用、服务验收、Git 提交/推送或包发布。

| 检查 | 结果与边界 |
|---|---|
| 本地文档链接与标题锚点 | 共检查 120 份文档，1,145 个本地链接及其中 10 个标题锚点通过；不等于远端网站可用性检查 |
| 双语配对 | 59 组顶层文档及根 README 均有对应中/英文文件；主要改写页面人工对照语义，不声称机器已验证全文翻译质量 |
| README 示例 | 中英代码相同，`ast.parse` 语法通过；19 个导入名在公开源码中存在；构造签名、注册句柄清理与返回字段已核对。输出仅标注为预期，未运行 |
| 安装与 CLI | 版本 2.0.0、Python 3.11+、10 个 extras 与 `setup.py` 一致；入口页命令及参数按 CLI 源码核对，未执行命令 |
| 当前状态表述 | 非历史页面的候选/未发布冲突已清理；路由和插件依赖的技术概念“候选”不删除 |
| 非文档内容与历史保护 | 411 个预先记录的源码、测试、示例、包配置及历史文档 SHA-256 均未变化 |
| 空白检查 | `git diff --check` 通过；现有工作区其他改动未回退或提交 |

## 参考与设计选择

README 组织参考 [smolagents](https://github.com/huggingface/smolagents#readme) 的简明定位、安装和快速示例，以及 [LangGraph](https://github.com/langchain-ai/langgraph#readme) 的能力说明与文档导航。只借鉴组织方式，没有复制文案、代码或性能承诺。`python-patterns` 用于示例的异步入口、公共 API 和显式注册生命周期设计。
