# W-Agent 2.0.0

[English](./2.0.0.en.md) | 简体中文

面向本地开发者的正式基础版，Python 3.11+，导入包仍为 `w_agent`。是否已经上传以 [PyPI 2.0.0](https://pypi.org/project/wagent-framework/2.0.0/) 为准；本文描述版本范围，不把候选构建当作发布成功。

## 基本范围

基础清单 B01–B12 覆盖可替换协议/统一注册表、四种插件入口、八组模型厂商模板与通用 HTTP、路由/有证据的探测、ReAct 工具循环、三种 Workflow、基础工具/MCP、知识导入检索、Run/Session、输入输出 Token 和预算、Docker/显式 unsafe-local、工程分享版本、CLI/TUI 和本地评测。详见[基础清单](../stable-release-baseline.md)和[客服/编码入门](../basic-development.md)。不内置租户或托管服务。

本轮修复：

- 本地模型目录不再被误报为连通或鉴权通过；远端目录成功只证明目录连通，不证明生成权限。自定义 HTTP 映射的证据按实际调用路径隔离记录，不增加默认付费探测。
- 插件加载批次、卸载、替换和生命周期通知中的取消，先完成已拥有资源的清理，再传播取消；重复取消不会遗留后台清理任务。
- 新增实际客服/编码模板组合示例及回归，默认离线，不暗授文件修改、命令执行或真实模型访问权限。

## 验证与限制

源码定向验收分组通过：核心链路 282 项、插件 76 项、模型探测 50 项及相邻计量 91 项、模板组合 12 项、底座/预算/评测 84 项；版本调整后关键修复交叉检查 45 项。组间有重复用例，不能相加称为独立测试总数；本轮没有跑全量测试。

Docker 29.2.1 的真实验收使用本机已缓存 `node@sha256:c610fcdfb1d5b4740dd70c284ed3cb16bb857e0f7166196e36a5501df7a3aa32`，未拉取镜像；断网、只读根/工作区、非 root、移除 capabilities、禁止提权、内存限制、临时目录写入、显式环境、超时及自有容器清理通过。源码 TUI 宽屏/窄屏/缩放回切冒烟通过。

最终 wheel/sdist 内容、隔离安装和上传结果由[基础清单](../stable-release-baseline.md)跟踪。真实模型服务、实际计费、远端向量数据库和所有操作系统组合没有在本轮验证。不把离线确定性示例称为真实模型质量验收。

稳定版号承诺基础开发入口，不将标记 `Experimental` 的高级功能自动改为稳定。原生游标全前端接线、高级知识维护、在线插件市场、更多沙箱/Agent 类型等按[路线图](../roadmap.md)后续优化。

## 升级

1.x 工程底座保留；旧文本 Agent 可用 `LegacyAgentAdapter` 接入。2.0 需要 Python 3.11+。代码工厂、分享码、模型调用、本地执行和外部写入仍各有独立授权，不因升级自动开启。

```bash
python -m pip install "wagent-framework[models,tui]==2.0.0"
```

正式上传前可将版本要求替换为本地候选 wheel 路径。示例不作为 wheel 的 `examples` 包分发，应从同版本源码复制至用户项目。
