# 2.0.0a6 发布说明

[English](./2.0.0a6.en.md) | 简体中文

版本日期：2026-09-27。包名 `wagent-framework`，导入名 `w_agent`，Python 3.11+。本版集中交付审批恢复与事件展示基础，新增能力均为 `Experimental`，不代表框架开发完成。

## 相比 a5 的更新

- Workflow 内 Agent 的 CLI/TUI 批准并恢复：显式异步工厂装配、精确父子标识、独立代码/审批/执行确认，装配前后复核检查点，结束或取消时清理临时授权。
- `ToolContinuation`、可选恢复协议和 ReAct schema 2 检查点：未完成工具保存票据，通过独立处理器续执行；无票据保持 schema 1，不自动重跑初始工具或前序模型请求。
- `resumable_workflow_tool()`：Agent→Workflow 引用优先的暂停/续执行桥，保留父子关联；不改变旧 `workflow_start_tool()` / `workflow_resume_tool()` 的语义。
- 双层审批协调服务、CLI 及 TUI Approval chains 页：只读关联、显式选行、父子权限分离、四项独立确认，仅从父 Agent 恢复入口推进。
- `RunEventAccumulator`、可替换 `RunEventReducer` 与版本化 `RunReplaySnapshot`：跨分页重建已记录的文本、工具状态和媒体展示；默认隐藏内容、快照有界、失败页不推进原快照。不执行模型/工具，不代替执行检查点。
- TUI 页签回归改为核对完整的 11 个页面标识，覆盖新增审批页；保留大字符欢迎标识、颜文字和窄窗口降级。
- 中英 README、指南、API、Workflow、工具、事件回放和路线图同步更新。

## 兼容与边界

- 新版读取端支持 schema 1/2；旧版不保证读取含续执行票据的 schema 2 检查点，应先升级恢复端。
- 工厂是开发者明确授权的可信本地 Python，不是沙箱；需忠实装配相同 Store 与授权回调。查询/快照匹配不等于授权。
- 依赖可信本地文件系统和单执行者。跨 Store 原子提交、分布式锁、任意深度递归审批与崩溃后的恰好一次执行未实现；不确定执行保留 `RESUMING`，不得自动重放副作用。
- 展示快照不是执行恢复点，也不是日志真实性证明。默认 CLI/TUI 仍使用脱敏事件视图；富内容累积界面尚未接入。
- 工具结果正文尚未记录到 `TOOL_COMPLETED`；未记录的内容不能通过回放推断。

## 安装

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a6"
wagent --version
wagent tui
```
