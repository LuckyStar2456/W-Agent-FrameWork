# 2.0.0a4 发布说明

[English](./2.0.0a4.en.md) | 简体中文

发布日期：2026-09-27。包名 `wagent-framework`，导入名仍为 `w_agent`，要求 Python 3.11+。这是可选能力继续完善的 Alpha，不代表路线图已经全部完成。

## 相比 a3 的更新

- 用量与费用：可替换的调用前 Token/费用估算、预算软阈值事件、重试与续流费用包络，以及按 Agent 跨 Session 汇总。
- 事件：显式文本、工具参数和图片/音频事件；只读游标分页；默认脱敏、字段选择、嵌套路径与多模态披露投影。媒体正文仍需显式开启。
- 模型与工具：Gemini 原生媒体 Part Mapper、Provider 原生游标续流协议与执行器接线、显式 MCP 2025 初始化与 HTTP Session 协商。
- 插件与工程分享：锁定 wheel/SHA-256 目录、可审阅安装来源、Sandbox 安装与独立加载确认、来源核对及内容树复验。
- Workflow：有界异步 DAG 并行、可替换节点调用、显式同步线程模板、按 Run ID 的边界暂停和恢复。
- TUI：字符拼接的大号 `W-AGENT` 与颜文字，宽窄窗口适配；后台 Workflow 恢复、精确绑定暂停、可选同步线程执行。请求暂停与实际暂停分开展示。
- 开发体验：版本化本地评测套件、双语能力状态及发布文档；sdist 显式包含双语文档与测试源代码。

## 验证方式与边界

最终结果：Windows / Python 3.11.9 独立环境安装 wheel 后，全量 **405 项通过**（43.43 秒），并确认安装目录的 124 个 Python 文件与发布源码逐字节一致。CLI 版本、`pip check`、关键 Ruff 规则、真实 Docker 冒烟和宽窄窗口 TUI 冒烟均通过。

发布前运行完整 pytest（包含 `comprehensive_*.py`）、CLI/TUI 针对性回归、关键静态检查，并对构建产物进行安装、元数据、文件内容和命令入口检查。真实 Docker 冒烟使用本地缓存的 `node:22-alpine`，验证默认断网配置、非 root、能力移除、只读根与工作区、可写临时目录、显式环境变量、超时与容器清理。TUI 冒烟覆盖 120×42、45×30 和恢复宽屏，输出可审阅 SVG。

模型 API、MCP、插件安装主要由模拟传输/执行器测试覆盖；这不代表所有真实模型、MCP 服务器或远程包源已经在线验收。Wasm/nsjail 新协议适配与跨平台验收不属于本次通过范围。本地依赖可能产生第三方弃用警告，不能据此宣称零警告。

本版修正了横幅缩放使用旧窗口尺寸的问题；安装预览测试按“显示源站、隐藏路径”校准，事件面板测试按默认隐藏不受约束标识符校准。审批的精确 Call ID 仍由独立 Checkpoint 流程处理。

安装包审计同时修正了日志脱敏子包未进入 wheel 的问题，并让 Serverless 示例随 sdist 分发。隔离安装测试显式加载部署示例，不把仓库根目录加入导入路径，避免源码遮蔽实际安装包。

## 安装

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a4"
wagent --version
wagent tui
```
