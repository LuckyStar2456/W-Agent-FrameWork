# 2.0.0a8 release notes

English | [简体中文](./2.0.0a8.md)

Release date: 2026-09-27. Distribution `wagent-framework`, import `w_agent`, Python 3.11+. This release collects post-a7 context, field-control, TUI-cache and summary-accounting additions. New features are `Experimental`; this is not the completed framework.

## Additions since a7

- Replaceable local keyword-retrieval and extractive-summary templates, recent-segment retention and input/output bounds; explicit CLI/TUI options with separate `TRANSFORM HISTORY` consent.
- Python Runtime async history/retrieval/summary protocols with awaiting, cancellation, callback timeouts and post-preparation Session-change detection. Hosts explicitly inject external callbacks; no automatic network calls or retries.
- `AgentSessionHistorySummarizer` uses independent Agent Runs, a prompt-free observer and summary-specific token/cost budgets. Defaults allow one step and no tool calls and require Usage; hosts should still assemble a dedicated empty tool catalog.
- `InMemorySessionSummaryObserver` and explicit aggregation: idempotent reports by summary Run ID, replacement of resumed cumulative main results, incomplete flags for missing usage, and cost groups by currency/price-table version.
- Optional input `name/metadata` wrapper records with independent sending, recording, historical reuse and Replay disclosure. CLI/TUI selections default off, never modify the shared recorder or infer authority from fields.
- TUI Replay trusted-cache import/continuation and explicit new-file export, interoperating with CLI JSON. Includes separate confirmations, source/projection validation, no overwrites, background tasks and stale-result rejection.
- Restored `--history` in invalid CLI history-option diagnostics; regression assertions no longer depend on terminal wrapping.
- Retains large-character/emoticon TUI branding, media input, Agent/Workflow approval and continuation, and the 1.x engineering foundation. Both language editions of README, API, topic guides and roadmap are updated.

## Compatibility and boundaries

- Import remains `w_agent`. a7 text defaults remain; wrapped name/metadata content requires a8 decoders/projectors. Old input-media caches have different projection identities and must be regenerated.
- History defaults to text. Display, recording and Provider resending are independently authorized. Disabling additional recording does not disable other events, checkpoints or Provider logs. Custom Python extensions are trusted host code, not a security sandbox.
- Summary and main calls are independent Runs. Explicit aggregation is accounting, not a shared preparation/main-call hard budget; it neither modifies Session totals automatically nor supplies a durable observer. Concrete retrieval services, embedding accounting and automatic CLI/TUI model-summary assembly remain host concerns.
- Cancellation/timeouts are cooperative and cannot undo external side effects. Session-change detection is not a cross-process transaction.
- Cache binding is not authenticity signing. Import trusted caches only; original Stores are required, so this is not an offline cache reader. Export creates new files only; failure can leave a partial new file, and clearing/exiting cannot undo an already-started write.

## Install

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a8"
wagent --version
wagent tui
```

## Remaining modules

Shared pre-call reservations, durable preparation accounting and automatic Runtime/CLI/TUI totals; concrete external retrieval backends; dedicated TUI media rendering; additional Provider multimodal outputs, native cursors and cross-process continuation; advanced MCP; sandbox network policies, legacy adapters and real-environment acceptance; online plugin discovery/locking/upgrades; final end-to-end Agent-development acceptance.

Multi-agent, deep/distributed Workflow, cross-Store atomic transactions and a signed trust network remain reserved designs; see the [roadmap](../roadmap.en.md).
