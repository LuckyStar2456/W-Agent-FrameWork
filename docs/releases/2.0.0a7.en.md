# 2.0.0a7 release notes

English | [简体中文](./2.0.0a7.md)

Version date: 2026-09-27. Distribution: `wagent-framework`; import: `w_agent`; Python 3.11+. This release focuses on composable media input, Session context and read-only replay. Additions are `Experimental`; framework development is not complete.

## Changes since a6

- `LocalAgentRuntime.run_messages()` and strict bounded JSON input manifests, retaining text `run()`. CLI `--input-file` accepts ordered text, image and audio blocks.
- Replaceable `SessionInputRecorder` / `SessionInputDecoder`; explicit recording uses Session schema 2. Schema 1 remains readable and additional media recording defaults off.
- Replaceable history policies: text-only by default, explicitly recorded media, or no history. Recording, display disclosure and resending require independent decisions.
- Optional tool-result event bodies with separate disclosure, cross-Run `SessionEventReplay`, bounded immutable snapshots and replaceable sources/message projectors.
- Read-only JSON CLI `run-view` / `session view` with source-bound trusted cache continuation. The twelfth TUI Replay page offers in-memory snapshots, per-read content consent and display slicing.
- TUI Run media files and separate confirmations, immutable request capture, background execution/duplicate prevention, cancellation and exit cleanup. Live events retain the latest 200 safe projections; large-character branding, emoticons and narrow-screen fallback remain unchanged.
- Updated bilingual README, Runtime, Session, API, TUI, replay documentation and roadmap.

## Compatibility and boundaries

- a6 readers may not support Session schema 2; upgrade readers before sharing those records. The recording switch does not disable existing RunEvents, checkpoints, Provider logs or model recordings.
- Built-in manifests accept only user-message text/image/audio. Custom types use Python protocols. Input parsing and Replay never automatically download media URLs; actual model capability needs separate validation.
- Custom recorders, decoders, history policies and tool imports are trusted host code. JSON cannot grant execution authority. History reuse may send sensitive media to the selected Provider.
- Snapshots are not execution checkpoints, log-authenticity proofs or permission grants. Source binding is not a signature; load caches only from trusted sources. Input/output blocks have separate disclosure and cannot reconstruct unrecorded content.
- TUI cancellation cannot undo completed side effects or automatically replay a run. Synchronous Python may block the UI. Read-only threads may finish already-started file reads.
- Sessions register summaries after an invocation returns; unregistered runs do not appear in cross-Run views. Cross-store atomic commits, distributed locks and arbitrary execution-stack recovery are outside this release.

## Installation

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a7"
wagent --version
wagent tui
```

## Remaining modules

Retrieval/summarization context templates, optional name/metadata preservation, TUI cache import/export and dedicated media rendering; other vendors' multimodal output, native-cursor adapters and cross-process continuation; advanced MCP; sandbox network policy, legacy-backend adapters and broader live-environment acceptance; online plugin discovery/locking/upgrades; final complete Agent-development-chain acceptance. Multi-agent support, deep/distributed workflows, cross-store atomic transactions and signature trust networks remain reserved; see the [roadmap](../roadmap.en.md).
