# W-Agent 2.1.0

[English](./2.1.0.en.md) | 简体中文

2.1.0 将已完成 M0–M5 验收的 Spring 式 Harness 开发核心纳入正式版本：IoC、DI、AOP 与生命周期用于开发用户自己的执行体系，ReAct/Workflow 是可选装配。Python 3.11+，导入名仍为 `w_agent`。上传状态以 [PyPI 2.1.0](https://pypi.org/project/wagent-framework/2.1.0/) 为准；本文描述版本范围，不把构建成功当作上传成功。

## 新增核心

- `AssemblyPlan` 与 `ApplicationContext`：统一依赖校验、组件所有权、作用域、初始化回滚、取消和清理。
- `compile_assembly`、`compile_decorated`、`compile_configured`：显式 Python、注解、配置共用计划；配置只选择宿主允许的定义。
- `Configuration`/`Bean`、组件扫描、类型/限定注入、`Value` 绑定与生命周期注解。
- `Aspect`、Before/Around/After/OnError/Finally：同步、异步和流调用的切面与清理，插件桥接保留自定义作用域顺序。
- `ApplicationProject`/`ApplicationHost`：Python、CLI/TUI 的公开项目执行；默认 Runtime/Workflow 的 Loop、路由与执行器可替换。
- 自定义 Harness、注解客服、配置编码三条双语教程及离线示例。

## 安装与开发

```bash
python -m pip install "wagent-framework==2.1.0"
# 按需启用 HTTP 模型与 TUI
python -m pip install "wagent-framework[models,tui]==2.1.0"
```

从[开发自己的 Harness](../harness-development.md)和[README](../../README.md)开始；旧容器、代理和同步 Runtime 不会自动变成新语义，见[迁移说明](../migration-1x.md)。wheel 不分发 `examples` 包，示例及伴随 JSON 可从匹配的 sdist/源码复制。

## 验收依据与发布边界

复用[核心终验](../harness-acceptance.md)：259 项相关测试、33 文件静态检查、中英 README 实际执行、离线 wheel/sdist、隔离安装及仓库外三示例 Python/CLI/无显示 TUI 通过。此次发布只调整版本/包描述与文档；框架源码与终验制品逐字节比较，仅 `__version__` 由 2.0.0 改为 2.1.0。发布阶段不重跑测试、不新增安装、不调用真实模型，不进行 Git 提交/推送。

正式制品进行源文件/元数据一致性核对和 `twine check --strict`，上传后另核对 PyPI 两份制品摘要。不声称已经从 PyPI 重装。此前本地候选的 2.0.0 元数据只是验收标识，不是重发或覆盖 PyPI 2.0.0。

## 保留限制

普通 Python/插件/切面为受信代码，不是安全沙箱；逐次批准和强制预算不能仅由可移除切面承担。Host 不监管私自启动的后台任务或强行中断不协作同步代码。CLI/TUI 仅承载支持的 JSON/显示类型；编码示例只改内存、不执行生成代码。

无全量回归、真实模型质量/计费或全平台验证；此前标记 Experimental 的外围能力不因版本号自动稳定。多 Agent、分布式 Workflow、远程沙箱、插件市场、高级热迁移仍保留，见[路线图](../roadmap.md)。
