# 2.0.0a7 发布说明

[English](./2.0.0a7.en.md) | 简体中文

版本日期：2026-09-27。发行包 `wagent-framework`，导入名 `w_agent`，Python 3.11+。本版聚焦可装配的媒体输入、Session 上下文和只读回放，新增能力为 `Experimental`；框架开发尚未完成。

## 相比 a6 的新增能力

- `LocalAgentRuntime.run_messages()` 与严格有界 JSON 输入清单，保留文本 `run()`；CLI `--input-file` 支持有序文本、图片、音频块。
- 可替换 `SessionInputRecorder` / `SessionInputDecoder`，显式记录后使用 Session schema 2。旧 schema 1 继续可读，默认不额外保存媒体。
- 可替换历史策略：默认仅文本、显式使用记录的媒体、或关闭历史；输入记录、展示披露和再次发送分别授权。
- 可选工具结果事件记录与独立披露、跨 Run 的 `SessionEventReplay`、有界不可变快照、可替换数据源与消息投影器。
- CLI `run-view` / `session view` 的只读 JSON 视图、绑定来源的受信缓存续读；TUI 第十二个 Replay 页提供内存快照、逐次内容确认和分屏展示。
- TUI Run 媒体文件与独立确认、捕获不可变请求、后台执行/重复提交防护、取消及退出清理。实时事件只保留最近 200 条安全投影；大字符标识、颜文字和窄屏适配保持不变。
- 更新双语 README、Runtime、Session、API、TUI、回放文档和路线图。

## 兼容与边界

- a6 读取器可能不支持新的 Session schema 2；共享此类记录前应先升级读取端。记录开关不关闭既有 RunEvent、Checkpoint、Provider 或模型录制日志。
- 内置清单只接受用户消息的文本/图片/音频；自定义类型通过 Python 协议扩展。媒体 URL 不由输入解析或 Replay 自动下载；实际模型支持须单独验证。
- 自定义记录器、解码器、历史策略及工具导入属于受信宿主代码，JSON 不能授予执行权限。历史复用可能向选定 Provider 发送敏感媒体。
- 快照不是执行检查点、日志真实性证明或权限凭据。源绑定不是签名认证；缓存仅应从受信来源加载。输入块与输出块分别披露，不能补齐未记录的内容。
- TUI 取消不撤销已发生的副作用，也不自动重跑；同步 Python 代码可能阻塞界面。只读线程可能完成已开始的文件读取。
- Session 在运行返回后登记摘要；尚未登记的运行不出现在跨 Run 视图中。跨 Store 原子提交、分布式锁与任意执行栈恢复不在本版范围。

## 安装

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a7"
wagent --version
wagent tui
```
