# W-Agent 2.0.0

English | [简体中文](./2.0.0.md)

The stable basic framework for local developers, requiring Python 3.11+, still imported as `w_agent`. Publication is determined by [PyPI 2.0.0](https://pypi.org/project/wagent-framework/2.0.0/); this document defines release scope and does not equate a candidate build with a successful upload.

## Basic scope

Baseline B01–B12 covers replaceable protocols/unified registry, four plugin entries, eight vendor groups and generic HTTP, routing/evidence-based probing, ReAct tool loops, three Workflow forms, basic tools/MCP, knowledge ingestion/retrieval, Run/Session, input/output tokens and budgets, Docker/explicit unsafe-local, versioned project sharing, CLI/TUI and local evaluation. See the [baseline](../stable-release-baseline.en.md) and [support/coding starter](../basic-development.en.md). No tenancy or hosted platform is introduced.

Fixes in this batch:

- Local model catalogs no longer falsely prove connectivity/authentication. Remote catalog success proves catalog connectivity, not generation access. Custom HTTP mapping evidence records the actual call path in an isolated context, without default billed probes.
- Cancellation during plugin batches, unload, replacement and lifecycle notification completes owned cleanup before propagation; repeated cancellation does not detach cleanup tasks.
- Actual support/coding template examples and regressions are offline by default, without implicit file writes, command execution or live model permissions.

## Verification and limits

Focused source groups passed: 282 core-chain tests, 76 plugin tests, 50 model/probe tests plus 91 neighboring accounting tests, 12 template tests and 84 foundation/budget/evaluation tests; 45 critical-fix cross-checks passed after the version update. Groups overlap and must not be summed as a unique-test total. No full-suite run occurred in this batch.

Live Docker 29.2.1 acceptance used cached `node@sha256:c610fcdfb1d5b4740dd70c284ed3cb16bb857e0f7166196e36a5501df7a3aa32`, with no pull. Network isolation, read-only root/workspace, non-root execution, dropped capabilities, no-new-privileges, memory limit, temporary writes, explicit environment, timeout and owned-container cleanup passed. Source TUI wide/narrow/resize-back smoke also passed.

Final wheel/sdist contents, isolated installation and upload are tracked by the [baseline](../stable-release-baseline.en.md). Live model services, actual billing, remote vector stores and all OS combinations were not verified this batch. Deterministic offline examples are not model-quality acceptance.

The stable version covers basic development entries; advanced APIs labeled `Experimental` do not automatically become stable. Full frontend native-cursor wiring, advanced knowledge maintenance, online plugin marketplaces and further sandbox/Agent styles remain in the [roadmap](../roadmap.en.md).

## Upgrade

Legacy engineering primitives remain, with `LegacyAgentAdapter` for old text Agents. 2.0 requires Python 3.11+. Code factories, sharing codes, model calls, local execution and external writes retain independent authorization; upgrading does not enable them automatically.

```bash
python -m pip install "wagent-framework[models,tui]==2.0.0"
```

Before publication, use a local candidate wheel instead of the version requirement. Examples are not a wheel-provided `examples` package; copy them from matching source into your project.
