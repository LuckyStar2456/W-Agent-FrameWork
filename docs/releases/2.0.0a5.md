# 2.0.0a5 发布说明

[English](./2.0.0a5.en.md) | 简体中文

发布日期：2026-09-27。包名 `wagent-framework`，导入名 `w_agent`，要求 Python 3.11+。这是针对本地暂停与审批恢复的增量 Alpha，不代表框架开发完毕。

## 相比 a4 的更新

- `SQLiteWorkflowPauseController`：按精确 Run ID 持久化本地跨进程暂停请求，新增 CLI 请求、状态、清除和显式恢复监听。读取错误失败关闭；清除不等于恢复，请求不等于已暂停。
- `AnyWorkflowPauseSource`：有序只读 OR 组合。TUI 可显式组合本次进程内暂停与 SQLite 请求，任务结束不清除外部持久请求。
- `WorkflowNodeResult(suspend=True, pause=True)`：保存状态但保留当前节点未完成，产生 `node-suspended` 事件；兼容原有“完成节点后暂停”。
- `approval_agent_workflow_node()` 与可选 `ResumableAgentLoop`：Workflow 内 Agent 待审批时保留精确子 Run/Call 引用，核对定义、作用域和检查点后，以新的明确授权继续同一子 Run。
- `review_workflow_approvals()`、CLI `checkpoint workflow-approvals` 与 TUI 只读查询：展示父子标识和匹配状态，不显示消息或工具参数，不导入代码，不授予权限。
- `WorkflowApprovalGrants`：宿主显式注入的一次性内存授权，绑定引用与作用域，默认 300 秒过期，可撤销或清空；仅消费当前 Call ID，不隐式批准后续调用。
- 修正旧 AOP 与动态配置模块的类型名导入；同步中英 API、Workflow、TUI、路线图和入口文档。

## 兼容与限制

- 原有节点、暂停和公开 WorkflowStore 合约保持不变。新增事件枚举值 `node-suspended` 可能不被旧版本事件读取器识别，应先升级读取端。
- SQLite 请求只面向可信本地文件系统，不提供运行锁、进程存活证明或多主恢复。
- 宿主必须显式装配同一 Agent Store 与授权回调。CLI/TUI 本版只提供审批关联查询，完整“批准并恢复”交互仍待实现。
- 父子 Store 不具备原子事务；不确定执行保留 `RESUMING`，禁止自动重放副作用。一次性授权也不承诺崩溃后的恰好一次执行。

## 安装

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a5"
wagent --version
wagent tui
```
