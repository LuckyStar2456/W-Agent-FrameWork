# 2.0.0a4 release notes

English | [简体中文](./2.0.0a4.md)

Release date: 2026-09-27. Distribution: `wagent-framework`; imports remain under `w_agent`. Python 3.11+ is required. This alpha develops optional capabilities and does not represent completion of the roadmap.

## Changes since a3

- Usage and cost: replaceable pre-call token/cost estimation, soft-budget events, retry/continuation cost envelopes, and per-agent aggregation across sessions.
- Events: opt-in text, tool-argument, and image/audio events; read-only cursor paging; default redaction, field selection, nested paths, and multimodal disclosure projections. Media bodies remain opt-in.
- Models and tools: native Gemini media Part mapping, provider-native cursor contracts and executor wiring, and explicit MCP 2025 initialization/HTTP session negotiation.
- Plugins and project sharing: locked wheel/SHA-256 catalogs, reviewable installation origins, sandbox installation with independent load confirmation, entry-origin checks, and content-tree verification.
- Workflows: bounded async DAG concurrency, replaceable node invocation, opt-in synchronous threading, and run-ID-scoped boundary pause/recovery.
- TUI: large `W-AGENT` character art and a kaomoji with narrow-window adaptation; background workflow recovery, exactly bound pause controls, and optional synchronous threading. Pending requests and actual pauses are displayed separately.
- Development: versioned local evaluation suites and bilingual capability/release documentation; sdists explicitly include bilingual docs and test sources.

## Validation approach and limits

Final result: after installing the wheel in an isolated Windows / Python 3.11.9 environment, **405 tests passed** in 43.43 seconds. All 124 installed Python files matched the release source byte for byte. CLI version, `pip check`, critical Ruff rules, real Docker smoke, and wide/narrow TUI smoke also passed.

Before publication, run the full pytest suite (including `comprehensive_*.py`), targeted CLI/TUI regression tests, critical static checks, and artifact installation, metadata, file-content, and entry-point checks. A real Docker smoke uses cached `node:22-alpine` to verify network-off configuration, non-root execution, dropped capabilities, read-only root/workspace, writable temporary storage, explicit environment variables, timeout, and container cleanup. The TUI smoke covers 120×42, 45×30, and restoration to a wide window, producing reviewable SVGs.

Model APIs, MCP, and plugin installation primarily have simulated transport/executor coverage; this is not live acceptance for every model, MCP server, or remote package index. New Wasm/nsjail protocol adapters and cross-platform acceptance are outside this release's passing scope. Local dependencies may emit third-party deprecation warnings; zero warnings are not claimed.

This release fixes banner resizing that used the previous terminal dimensions. Install-preview assertions now enforce visible origins with hidden paths; event-panel assertions reflect default removal of unconstrained identifiers. Exact approval call IDs remain handled by the separate checkpoint workflow.

Artifact auditing also fixed omission of the sensitive-logging subpackage from the wheel and includes the Serverless example in the sdist. Isolated installation tests load that deployment example explicitly without putting the repository root on the import path, preventing source files from shadowing the installed package.

## Install

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a4"
wagent --version
wagent tui
```

## Remaining work

Other vendors' media outputs, bundled native-cursor adapters/cross-process recovery, CLI/cross-process pause, agent/workflow approval cascading, advanced MCP, sandbox network policies/legacy adapters, and online plugin discovery/upgrades follow the [roadmap](../roadmap.en.md). Multi-agent execution, nested/distributed workflows, and signature trust networks remain reserved designs.
