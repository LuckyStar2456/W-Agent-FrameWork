# 2.0.0a9 发布说明

[English](./2.0.0a9.en.md) | 简体中文

发布日期：2026-09-28。发行包 `wagent-framework`，导入名 `w_agent`，Python 3.11+。本版收录 a8 后的共享预算、持久化计量与 CLI/TUI 接线；仍为 Experimental，不代表框架开发完成。

## 相比 a8 的更新

- 可替换共享预算协议及内存/SQLite 控制器：输入、输出、总 Token 与可选金额限额，调用前原子预留、按实际 Usage 结算；未返回 Usage 或中断保留未知额度，拒绝自动重试。
- 可替换 Provider 包装器；宿主提供可靠输入/输出/价格上界，摘要与主 Agent 可显式共用池。不把字符估算当作可靠上界。
- SQLite 显式初始化、配置绑定、事务入场、持久化票据与重开读取；宿主依据独立证据并确认没有活跃调用后，可对 pending/unknown 显式对账，保留幂等、不可覆盖回执。
- Runtime/Provider 具名绑定与原客户端生命周期管理；JSON 只引用绑定名称，不载入代码、不赋予授权，缺失绑定失败关闭。
- CLI run、run-resume、evaluate、provider-probe 与对应 TUI 表单支持独立授权的预算工厂和池快照。评测整批共池；安全探测不生成，主动探测按 8 输出 Token 上限的请求预留。保存的评测报告格式不变。
- 可替换 `SQLiteSessionSummaryObserver`，持久保存无正文的摘要 Run 用量报告，支持显式初始化、幂等更新、重开和显式归集。
- 中英文 README、API、Runtime、TUI、评测、预算、计量及路线图同步。保留大字符/颜文字 TUI、1.x 工程底座与此前 Alpha 功能。

## 使用与边界

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a9"
wagent --version
wagent tui
```

- 默认不启用共享预算。`shared_budget.binding` 必须匹配宿主提供的 controller/meter；CLI 另外要求 `--budget-entry module:factory --confirm-budget-code`，TUI 要求逐次 `LOAD BUDGET`。模型、工具、审批确认仍独立。工厂是受信非沙箱宿主代码。
- 共享预算覆盖已包装路由，不自动计入隐藏重试、未包装工具/嵌入/检索服务。原生游标计量尚未接入，配置组合在装配前拒绝。可靠上界由宿主对具体 Provider 负责，不能保证未知的厂商计费行为。
- 池快照不是本次 Run/评测的独占用量，不得重复相加；快照失败不改运行结果、不触发模型重跑。摘要报告、主 Run 和共享票据仍是独立账本。
- SQLite 用于受信本地文件；不构成租户隔离、执行租约、签名账本或跨文件事务。取消不等于退款，线程提交可能在取消后完成，须重开核查；不自动清理或核对厂商账单。
- a9 首次发布共享预算数据库格式：表/配置版本 1，普通票据版本 1，对账票据版本 2；不要混用不支持版本 2 的旧工作区实现。

## 当前进度与剩余模块

已推进预算与持久化计量，并贯通现有运行、恢复、评测及探测入口。剩余：准备阶段/主 Run 统一持久账本和自动归集；具体外部检索后端；更多 Provider 媒体输出及原生游标/跨进程续传；TUI 专用媒体渲染；高级 MCP；沙箱网络策略、旧适配器与真实环境验收；插件在线发现/锁定/升级；完整 Agent 开发链路最终验收。

多 Agent、深度/分布式 Workflow、跨 Store 原子事务与签名信任网络继续保留设计。详见[路线图](../roadmap.md)。
