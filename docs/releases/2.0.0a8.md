# 2.0.0a8 发布说明

[English](./2.0.0a8.en.md) | 简体中文

版本日期：2026-09-27。发行包 `wagent-framework`，导入名 `w_agent`，Python 3.11+。本版整理 a7 后的上下文、字段控制、TUI 缓存与摘要计量增量，新增能力均为 `Experimental`。这不是框架最终版。

## 相比 a7 的新增能力

- 可替换的本地关键词检索与抽取式摘要模板，保留近期消息段并限制输入/输出大小；CLI/TUI 提供显式参数和独立 `TRANSFORM HISTORY` 确认。
- 异步历史策略、检索器与摘要器协议接入 Python Runtime，支持等待、取消、回调超时及准备后 Session 变化检测；宿主显式注入外部回调，无自动网络请求或重试。
- `AgentSessionHistorySummarizer` 使用独立 Agent Run、无正文观察器与摘要自身 Token/费用预算；默认一步、零工具调用、要求 Usage，宿主仍应装配专用空工具目录。
- `InMemorySessionSummaryObserver` 与显式用量归集：摘要报告按 Run ID 幂等更新，主 Run 恢复后的累计结果替换旧快照，缺失用量标记不完整，费用按币种/价格表版本分组。
- 可选输入 `name/metadata` 包装记录与独立发送、保存、历史复用、Replay 披露。CLI/TUI 分别控制，默认关闭，不改变共享默认记录器或从字段推导权限。
- TUI Replay 受信缓存导入续读与显式新文件导出，兼容 CLI JSON 格式；双重确认、来源/投影校验、拒绝覆盖、后台任务和过期结果丢弃。
- 修复无效 CLI 历史选项错误提示缺少 `--history` 标识的问题；回归断言不再依赖终端自动换行位置。
- 保留大字符/可爱颜文字 TUI、媒体输入、Agent/Workflow 审批与续执行，以及 1.x 工程能力；同步中英 README、API、专题和路线图。

## 兼容与边界

- `w_agent` 导入名不变。a7 默认文本行为保留；name/metadata 包装内容需要 a8 解码器/投影器。旧输入媒体缓存投影身份不同，须重新生成，不能自动续用。
- 默认仅文本历史；展示、保存和再次向 Provider 发送分别授权。记录关闭不关闭其他事件、Checkpoint 或 Provider 日志。自定义 Python 扩展是受信宿主代码，不是安全沙箱。
- 摘要与主 Run 是独立 Run。归集只是显式统计，不是跨准备/主调用的共享硬预算，不自动修改 Session 统计或提供持久化观察器。具体检索服务、嵌入费用和自动 CLI/TUI 模型摘要接线仍由宿主管理。
- 取消与超时依赖协作，不撤销已发生的外部副作用。Session 变化检测不是跨进程事务。
- 缓存绑定不是真实性签名。只加载受信缓存；导入仍需原 Store，不是离线缓存阅读器。导出仅创建新文件；失败可能留下部分新文件，清空或退出不能撤销已经开始的写入。

## 安装

```sh
python -m pip install --pre "wagent-framework[models,tui]==2.0.0a8"
wagent --version
wagent tui
```
