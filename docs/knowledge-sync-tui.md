# 知识增量同步 TUI

> 适用版本：2.0.0。`Experimental` 仍为实验性接口；`Planned` / `Reserved` 不表示已实现。验证范围见[正式版记录](./acceptance-2026-10-01-stable-release.md)。

[English](knowledge-sync-tui.en.md)

2.0.0 Experimental。专用 `Knowledge sync` 页提供本地同步计划检查与显式宿主操作；与 CLI 复用同步管理服务，不建立另一套状态机。原大字符欢迎页保持不变。

## 完整本地入口

1. 填写追溯库、namespace/version、受信 root、相对路径 JSON 数组、分块字节数，输入 `READ SYNC`，点击“追溯导入预览”。只读，不创建数据库；默认 UTF-8，可显式勾选启用可选 PDF/DOCX/XLSX/PPTX 解析。选择与解析器配置纳入预览锁，切换后须重新预览。依赖按需加载、缺失不自动安装；只处理受信文件，解析不构成沙箱。`[]` 是显式空版本，不是“使用默认路径”。
2. 审查预览后，**手填**返回的 `preview_digest`，输入 `READ SYNC` 与 `RECORD SYNC`；首次创建库另填 `CREATE SYNC`。点击“保存已批准追溯”。源文件或路径/配置变化时，锁定摘要不匹配会在创建库之前拒绝。
3. 手填保存的 `trace_digest`、同步日志库、受信 `module:factory` 与 binding；增量版本还需前驱已完成计划摘要和独立批准的缓存摘要。输入 `READ SYNC`、`LOAD INDEX HOST`、`RECORD SYNC`；有新增 Embedding 时另填 `EMBED SYNC`，新日志另填 `CREATE SYNC`。点击“准备并暂存”。此步可能计费并暂存精确向量/计划、锁定目标，但不发送 upsert/delete。
4. 填计划摘要，清空其他确认，仅输入 `READ SYNC` 点击检查。返回安全摘要、批次状态与可用的明确未发送重试候选，不加载宿主、不展示正文/向量/路径/远端 endpoint/证据引用。
5. 独立手填 plan 批准摘要；需要 upsert/delete 时各自填写对应批准摘要与 `UPSERT SYNC` / `DELETE SYNC`。再输入 `READ SYNC`、`LOAD INDEX HOST`、`RECORD SYNC`，点击执行。只有相应确认词与摘要成对才会传入管理服务，不能用 upsert 批准授权删除。

不同操作不接受无关确认词。准备时可省 `EMBED SYNC` 的唯一有用情形是底层确认所有块均可复用，无需新增模型调用。详情请参见[增量同步语义](knowledge-sync.md)。

## 授权与使用边界

默认不读文件、不加载宿主、不请求模型或索引。每个操作需填写精确路径/身份及所需确认词；确认词在捕获请求时一次性清空，无论请求是否有效。预览结果不会自动填写审批摘要，也不能授权执行。

运行中的请求捕获为独立对象；控件锁定，不能把之后编辑的参数混入操作。取消仅请求停止，不意味着回滚：Embedding 可能已计费，SQLite 可能已提交，远端请求可能已经发送。取消后先读取同一计划日志，禁止把未知结果当作未发送重试。

宿主 `module:factory` 是用户明确允许的本地不隔离 Python 代码，可自行访问文件/网络；确认加载代码并不等于框架隔离它。应只加载自己审查过的宿主。无须宿主的本地检查不能因为字段中留有入口而导入该模块。

计划、upsert、delete、记录写入是不同授权边界。同步可能删除旧版本自己的点，使旧版本远端检索不可用；应使用独占的专用集合。本页仅提供共享管理服务的安全摘要，不提供正文/向量/远端目标披露开关；需要审查目标配置时由受信宿主/API承担。结果以转义 JSON 展示并分屏，不执行终端控制字符或 Rich markup；翻页不做 I/O。

本页不提供自动重试/自动批准/后台轮询；`pending`、`unknown`、`acknowledged` 不自动重发。需要证据对账或确定未发送后的独立重试时，使用对应显式管理 API/CLI，而不是重复点击“执行”。

## 当前验证状态

后续文档格式轮次增加真实 DOCX 的显式勾选→预览→锁定保存→重开追溯回归。原始二进制归档是[单独 API](knowledge-archives.md)，本面板不自动归档或恢复原文件；格式/归档的最终定向数量以主任务本轮记录为准。

本轮专属面板测试已验证真实本地“预览 → 锁定保存 → 重开 trace”与源文件变化拒绝；其他定向用例覆盖独立授权、请求捕获、host-free检查、upsert/delete成对批准、失败/取消不自动重试、控件锁定和结果转义/分页。共享管理服务的真实宿主生命周期/索引传输由独立定向验收覆盖。具体数量以本轮最终验收记录为准；不以旧轮次全量测试证明新面板可用。未进行收费 Embedding、真实 Qdrant、依赖安装或发布。
